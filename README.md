# mobidraw

[![Project: mobidraw](https://img.shields.io/badge/project-mobidraw-blue?style=flat-square)](https://github.com/krishkr-ctl/mobidraw)
[![License: MIT](https://img.shields.io/badge/license-MIT-lightgrey?style=flat-square)](LICENSE)

A simple, mobile-friendly drawing web app built with plain HTML/CSS/JavaScript.

---

## Demo

Open `index.html` in your browser (desktop or mobile) to start drawing. The app is designed to work on touch devices as well as with a mouse.

## Features

- Draw with touch or mouse
- Select stroke color
- Adjust brush size
- Clear canvas
- Save drawing as an image (PNG)
- Lightweight: no frameworks required

## Usage

1. Clone or download the repository:

   ```bash
   git clone https://github.com/krishkr-ctl/mobidraw.git
   cd mobidraw
   ```

2. Open `index.html` in your browser (double-click or serve with a static server):

   ```bash
   # optional: serve with a simple static server
   npx http-server .
   # then open http://localhost:8080
   ```

3. Use the controls to change color and brush size, draw on the canvas, clear, or save your artwork.

## Keyboard & Touch Shortcuts

- Draw with mouse or single-finger touch
- Ctrl/Cmd + S — Save the canvas as an image (if implemented by the UI)
- Long-press on mobile for context actions (depending on browser)

> Tip: For best results on mobile, rotate your device to landscape for a wider drawing area.
